# Astra 研究工作室

一个 7 人专家团，陪你把一篇实证论文从选题做到投稿和审稿回复。

面向计算机方向的实证会议论文：软件工程类（ICSE、FSE、ASE）和机器学习类（NeurIPS、ICLR、ICML）。其他类型的论文可以单独使用其中的选题定位、模拟评审和审稿回复。

## 能做什么

- **选题定位**：文献矩阵，和最近的三篇工作逐项对比，一句话论点
- **开题**：研究问题、假设、通过和不通过的判据、图表计划、基线，冻结后留痕
- **实验台账**：每次运行只追加不修改，按冻结的判据区分正式运行和探索运行
- **结果与初稿**：结果表和图只从正式运行生成；正文只依据冻结的证据包撰写
- **模拟评审**：三位立场不同的审稿人各自独立审稿
- **投稿检查和审稿回复**：匿名检查、制品重跑、逐条回复表

## 怎么开始

说出你的研究想法和目标会议，例如「我想写一篇论文，先帮我做选题定位」。团队会在当前项目下建立 `.studio-paper/` 工作区保存台账和各阶段产物。

流程里有六个需要你或导师确认的节点。团队只做预审，不会代替任何人签字。实验由你自己跑，团队负责记录和汇总。

## 环境要求

Python 3；生成图需要 `matplotlib`。项目最好是 git 仓库，台账会记录每次运行对应的提交。
