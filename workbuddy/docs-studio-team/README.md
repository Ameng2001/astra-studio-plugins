# Astra 文书工坊

一个 7 人专家团，把招标文件和业务材料写成正式文档。

## 能做什么

- **写投标文件**：读招标文件，梳理需求和评分点，分章撰写，逐条核对响应
- **写方案和报告**：项目建议书、可行性研究报告、初步设计、建设方案、验收材料、招标文件
- **审校和导出**：按文档模板检查现成的稿子，导出带公文格式的 Word 和 PDF

## 团队

|------|------|
| Dora · 文书主理人 | 编排流程，做文档计划，列出需要你补充的资料 |
| Bea · 业务分析师 | 从材料里梳理画像、旅程和流程 |
| Archer · 方案架构师 | 评审总体方案和系统边界 |
| Wren · 撰稿人 | 按计划分章撰写 |

| Edie · 审校编辑 | 合并章节，检查合规，出质量报告 |
| Tess · 排版师 | 导出 Word 和 PDF |

## 怎么开始

把材料放进项目目录，然后直接说要写什么，例如「帮我写一份投标文件，招标文件在这里」。团队会在当前项目下建立 `studio/` 工作区保存分析和文档计划，成稿放在 `docs/`。

资质、业绩、报价、人员这类信息团队不会编造。材料里没有的，会列成清单请你补充。

需要固定某种文风时，说「帮我建一个写作专家」，并给几份范文。

## 环境要求

撰写和审校不需要额外环境。导出 Word 和 PDF 需要本机有 `pandoc`、Python 3（`python-docx` 包）；文档里有 Mermaid 图时还需要 `mmdc` 和 Chrome 或 Chromium。缺工具时团队会交付 Markdown 并说明缺了什么。
