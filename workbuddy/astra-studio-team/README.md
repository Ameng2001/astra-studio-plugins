# Astra 研发工作室

一个 7 人专家团，把业务想法落成可校验、可上架的插件。

## 能做什么

- **从零规划插件**：事件风暴 → 领域建模 → 技能设计 → 规格生成 → 技能初稿，每个阶段停下来等你确认
- **单独做业务分析**：用户画像、旅程图、流程图、领域画布、行为矩阵、机会评估
- **校验插件**：检查清单、目录结构、技能完整性、依赖和 MCP 配置，给出修复建议

## 团队

| Quinn · 质检员 | 运行校验脚本，出修复建议 |

## 怎么开始

直接说你想做的业务，例如「帮我从零规划一个插件：社区养老服务」。团队会在当前项目下建立 `studio/` 工作区保存设计文档，建议纳入版本管理。

需要特定行业的评审时，说「帮我建一个 XX 领域的专家」，之后的评审会自动用上。

## 环境要求

校验功能需要本机有 Python 3，只用标准库，不需要安装额外的包。

## 来源

由 [astra-studio-plugins](https://github.com/Ameng2001/astra-studio-plugins) 的 `studio-core`、`studio-insight`、`studio-planner`、`studio-quality` 四个插件组装而成。Apache-2.0。
