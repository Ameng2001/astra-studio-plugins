# 声称词表（scan_claims.py 的词典）

命中即进入 `review/claims.md`，要求比较对象 + 区间 / 检验，否则判「过强」。

| 词 | 要求 | 常见改法 |
|---|---|---|
| first / 首次 / 首个 | 近邻差异表能证明；重扫后仍成立 | 「据我们所知，在 X 设定下」+ 引近邻 |
| novel / 新颖 | 差异表指出具体差异 | 直接说差异是什么 |
| significantly / 显著 | 统计检验（名称 + p 或区间） | 给区间；或改「平均高出 x 点（95% CI …）」 |
| state-of-the-art / SOTA | 主表含当前最强基线且同预算 | 「在 benchmark B 上优于 …」并列基线 |
| outperforms / 优于 / 超过 | 表号 + n + seed 数 | 带表号与区间 |
| robust / 鲁棒 | 扰动实验表 | 指向扰动表 |
| generalizes / 泛化 | 跨数据集 / 跨 backbone 表 | 指向迁移表，写明范围 |
| consistently / 一致 | 全部 seed / 全部数据集 | 列反例或改「在 k/m 个设定上」 |
| 数字 + % / 倍 | 回指 run_id | 必须能回指台账 |

扫描规则：中英文并扫；量化句（含数字、百分号、「倍」）无论有无声称词都抽出回指。
