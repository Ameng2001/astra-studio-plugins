# ML 会议评审表（NeurIPS / ICLR / ICML 类，通用结构）

> 以当年模板为准。本文件是回退结构。

## 评审表字段

1. **Summary**
2. **Strengths / Weaknesses** — 常拆 originality · quality · clarity · significance
3. **Questions**
4. **Limitations** — 评审人评估作者是否诚实陈述
5. **Scores** — soundness · presentation · contribution 各维度 + overall + **confidence**
6. **Ethics / reproducibility checklist** 核对

驱动分数的是：基线是否强且调参公平、多 seed 与区间、消融、数据泄漏、benchmark 误用。

## Rebuttal 规则（通用）
- OpenReview 多轮往来，常有字符上限；可补表（标 T-R1 等），不可改研究问题。
- 评审人更新分数是 rebuttal 的实际效果，应回写组内经验。
