# Process: 实验入账与假设聚合（含回流）

> Domain: academic-paper · Date: 2026-10-23 · 覆盖事件 E9–E13

```mermaid
flowchart TD
    S[运行入口: 一次 run 结束] --> A[自动采集 commit/dirty · config哈希 · seed · metric · 耗时]
    A --> B[学生补填: rq · n · 污染关系 · 基线公平性 · 备注]
    B --> D5{◇D5 正式 or 探索性?}
    D5 -- 判据未冻结 / 缺污染或n字段 / n低于阈值 / 混杂 --> C1[入账 status=exploratory]
    D5 -- 全部满足 --> C2[入账 status=formal]
    C1 --> L[(台账 只增不删 作废需理由)]
    C2 --> L
    L --> R[E10 系统聚合: 每个RQ/H 支持·证伪·待定 + 覆盖矩阵]
    R --> D6{◇D6 某RQ判据未过?}
    D6 -- 否 --> F[等待全部RQ有结果]
    D6 -- 是 --> X[E11 论点偏离标记]
    X --> Y{导师: 改claim / 换实验 / 弃RQ}
    Y -- 改claim --> Z[回 E4 论点句, 版本+1]
    Y -- 换实验 --> W[回 E6 判据, E12 留痕]
    Y -- 弃RQ --> R
    F --> D7{🚪D7 冻结结果表?}
    D7 -- 否: 有RQ无表 / 挑窗挑种子 / 只有成功run --> S
    D7 -- 是 --> T[E13 结果表与图从台账生成并冻结]
    T --> U[E14 证据包交付 studio-docs]
```

## 硬规则（来自导师与审稿人）

1. 结果表**只能从台账生成**，不能手填；被排除的 run 必须披露排除理由。
2. 探索性 run **不能事后升级**为正式。
3. 台账行只增不删；作废写理由。
4. 冻结后再改实验视为新一轮（iteration +1，旧结果保留）。

## 瓶颈

- B 步的补填字段若超过 5 个，学生就不填 —— 入账负担是采用率的决定因素（架构师警告）。
- 对接现有日志（wandb / tensorboard / 裸日志）的方式未定（待裁定 #3）。
