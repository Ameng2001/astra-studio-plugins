# Process: 内审 → 投稿 → 回应 → 发表

> Domain: academic-paper · Date: 2026-10-23 · 覆盖事件 E15–E26

```mermaid
flowchart TD
    A[初稿 studio-docs 产出] --> B[E15 每条量化claim回指台账; 回指不到的删]
    B --> C[E16 模拟评审 #1 写作未完时: 3份评审表 + claim→证据表 + Top-3拒稿理由]
    C --> D8{🚪D8 fatal项处置}
    D8 -- 收窄claim --> B
    D8 -- 回到设计 --> R1[回 E6/E9]
    D8 -- fixable --> Q[待补实验队列 → 入账]
    Q --> C
    D8 -- 无fatal --> E[E16 模拟评审 #2 投稿冻结前]
    E --> F[E18 投稿前检查: 近邻重扫 · 声称词扫描 · 双盲 · artifact干净环境 · 哈希]
    F --> D9{🚪D9 投稿放行?}
    D9 -- 否 --> B
    D9 -- 是, 人点提交 --> G[E19 稿件投出 版本快照]
    G --> H[E20 外审意见拆解: fatal/fixable/误解/澄清 + 可移动性排序]
    H --> D10{◇D10 哪些补实验?}
    D10 --> I[E21 补充实验入账]
    I --> J[E22 逐条回应表: ID·原话·分类·回应·证据指针·run_id·修改承诺·新claim?]
    J --> D11{🚪D11 新数据削弱原claim?}
    D11 -- 是 --> K[强制收窄分支 + 同步camera-ready清单]
    K --> J
    D11 -- 否, 人确认提交 --> L[rebuttal 提交]
    L --> M{◇D12 决定}
    M -- reject --> N[改投: 回 E3 重对齐近邻与格式]
    M -- major revision --> O[E24 修订清单逐条兑现]
    M -- accept --> P[E25 camera-ready + artifact 数字一致性核对]
    O --> P
    P --> S[E26 rebuttal效果回写组内经验]
```

## 泳道

| 泳道 | 职责 |
|---|---|
| 学生 | claim 回指、意见拆解、补实验、回应表 |
| 运行时审稿人角色 ×3 | 近邻工作作者 / 方法统计 / 相邻领域读者 —— 填目标会议评审表 |
| 导师 | D8 / D9 / D11 签字；提交动作由人点 |
| 系统 | 声称词扫描、回指检查、匿名检查、哈希冻结、字数预算 |

## 硬规则

- 无回应表不得提交 rebuttal；每条回应引用的实验必须已入账。
- 评审表字段每年变，运行时读当年 CFP，不写死。
